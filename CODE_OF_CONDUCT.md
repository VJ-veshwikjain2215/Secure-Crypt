# Code of conduct

Keep discussions respectful, specific, and useful. Welcome contributors with different backgrounds and experience levels. Critique changes and ideas constructively.

Harassment, discriminatory remarks, threats, doxxing, spam, and publishing others' private data are not accepted. Do not post real passwords or private documents in examples.

The maintainer may edit or remove disruptive content, close discussions, or restrict participation when needed. For a private conduct concern, use the contact options on [Veshwik Jain's portfolio](https://veshwikjain.embarko.app/). Report software vulnerabilities through [the security policy](SECURITY.md), not a public discussion.
