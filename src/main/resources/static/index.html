Understand the Algorithms

A quick reference so you know exactly what's happening under the hood.

Caesar Cipher

A substitution cipher that shifts every letter by a fixed number of positions in the alphabet. Simple, but easily broken by brute force (only 25 possible shifts) or frequency analysis.

Educational / Weak
Vigenère Cipher

Uses a repeating keyword to apply a different Caesar shift to each letter, making pattern-based cryptanalysis much harder than a single-shift cipher.

Educational / Weak
XOR Cipher

Combines each byte of the message with a repeating key using the bitwise XOR operation. Extremely fast, symmetric, but insecure if the key is short or reused (key-reuse attacks).

Educational / Weak
AES-128

Advanced Encryption Standard with a 128-bit key, operating in CBC mode with PKCS5 padding and a random IV per message. The current global standard for symmetric encryption.

Industry Standard
DES

Data Encryption Standard - a 56-bit-key block cipher from the 1970s. Included here for academic comparison; considered cryptographically broken by modern brute-force standards.

Legacy / Deprecated
Triple DES (3DES)

Applies DES three times with a 192-bit key to strengthen the original algorithm. More secure than DES but slower and less secure than AES, now being phased out industry-wide.

Legacy / Transitional

About SecureCrypt

SecureCrypt is an academic mini-project built to demonstrate the practical working of classical and modern encryption algorithms. It was developed for the Fundamentals of Cyber Security course using a Spring Boot REST backend and a responsive Bootstrap 5 front end.

  • No data is ever stored on the server - every request is processed in memory and discarded.
  • Classical ciphers implemented manually; AES/DES/3DES implemented via the Java Cryptography Architecture (JCA).
  • Passwords for AES/DES/3DES are converted into cryptographic keys using PBKDF2 key derivation.
