02 / FIELD GUIDE

Different tools.
Different purposes.

Explore modern and historical ways to transform text. Start with the classics to understand the idea. Explore AES to see a modern cipher in action.

01AES-128MODERN CIPHER+

The most practical starting point here. Your passphrase is used to derive a key; a random initialization vector makes repeated encryptions look different.

New AES messages use authenticated GCM in your browser. To open older outputs, explicitly select legacy AES-CBC; it cannot verify integrity.

02CaesarCLASSICAL+

Move each Latin letter along the alphabet by a fixed number. A shift of 3 turns A into D. Try “Meet me at noon” with the key 3.

Easy to break. Only Latin letters are shifted; other scripts and emoji are preserved.

03VigenèreCLASSICAL+

A repeating keyword chooses a different shift for each letter. Try ATTACKATDAWN with LEMON to get LXFOPVEFRNHR.

An educational cipher, not secret protection. Non-Latin characters are preserved unchanged.

04XOREDUCATIONAL+

Combines the UTF-8 bytes of your text with a repeating key. The result is Base64 encoded so it can be copied as text.

A repeated key creates patterns. This is not a one-time pad.

05DES & Triple DESLEGACY+

Historical block ciphers included for comparison. DES has a small effective key size; Triple DES repeats the operation to extend it.

Keep these for learning and legacy examples. Do not choose them for new secret-protection systems.

03 / UNDER THE SURFACE

Built to make the
abstract a little tangible.

SecureCrypt is an educational project by Veshwik Jain ↗. Classical ciphers are implemented in Java; default AES uses browser Web Crypto, with an interoperable Java API.

AES-GCM and legacy AES decryption run locally using Web Crypto. Other algorithms send text and keys over HTTPS to our educational Java API. Browser-local processing does not protect against compromised devices or altered application code.
